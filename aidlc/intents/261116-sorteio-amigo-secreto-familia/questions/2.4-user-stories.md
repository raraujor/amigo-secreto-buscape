### Q4. [métrica] Como saber quem abriu o link, sem servidor? (follow-up da Q2 e do NFR-002)

Os requisitos aprovados dizem: hospedagem só no GitHub, custo R$ 0 (NFR-001, NFR-002). Um site no GitHub Pages não consegue gravar nada quando alguém abre o link; para registrar "abriu", é preciso um serviço externo ou outro caminho. Isso também reabre a 2.3, porque nenhum FR aprovado pede esse registro.

- A. Botão "Já vi! Avisar o organizador" na página do link, que abre o WhatsApp do participante com a mensagem "Vi meu amigo secreto ✅" para o seu número; você conta as confirmações no seu WhatsApp (sem servidor, R$ 0)
- B. Registro automático ao abrir, num serviço externo gratuito (ex.: banco de dados com plano grátis), aceitando sair do "só GitHub"; você vê a lista na sua área
- C. Deixar para depois do dia 28: a v1 não mede, você pergunta à família
- X. Outro (especifique)

[Answer]: B. "inclusive podemos usar esse mesmo banco de dados para gravar os participantes e os dados, assim não fica em arquivo".
